# GOH Coalition Partner Kit

A standalone searchable partner page at:
https://tangent-west.github.io/GOH_surfside/coalition/

This folder contains the partner page, four HTML emails, social artwork, captions, video, graphic customizer, and complete downloadable email and social ZIP kits.

The coalition page lives alongside the existing root gallery, website, and GOH content bank. It does not replace their pages or assets.

GitHub Pages publishes from the main branch and repository root. Keep this folder structure intact so previews, downloads, and the customizer retain their relative paths.
