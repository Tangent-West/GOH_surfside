# Adding supporter logos

The homepage logo wall and supporter directory share the same records and renderer. Add an organization once; counts, search and category options update automatically.

1. Verify the official company website. Append a unique kebab-case ID, display name, HTTPS URL, relevant category tags and original pixel dimensions to `candidates` in `data/staging-content.js`. Keep the existing order and check for duplicate organizations. Prefer existing categories; add a category when the organization's actual work is not covered (for example, Food & Nutrition). A listing must not imply the company sells cannabinoid products.
2. Copy the supplied logo unchanged into `assets/logos/originals/<id>.<original-extension>` and add its path to `suppliedLogos` in the same data file. PNG, WebP, JPEG and AVIF can be used directly. Set `viewBox` to `x y width height` around the artwork, leaving a small margin so nothing is clipped. Exclude unrelated screenshot artifacts outside the actual mark.
3. The default SVG treatment maps dark or colored artwork on white to the established muted ink (#716b63). For white or other single-color artwork on a genuinely transparent background, set `inkSource: 'alpha'`; it recolors the original silhouette while preserving transparency. Do not use alpha mode for an opaque image. For light artwork on a dark backdrop, `inkSource: 'light'` uses a 0.22 luminance cutoff to clear the backdrop; verify it does not hide artwork or leave a background rectangle. Other background tones may need a different treatment. Do not redraw a company logo.
4. Sizing is automatic in `organizationLogo`: it uses the cropped artwork's aspect ratio and a shared 12,000 px² target area, capped at 220 px wide and 100 px tall. This balances wide wordmarks against compact symbols without stretching them. The shared CSS scales all marks down together on smaller grids. Use an accurate artwork crop instead of adding individual width rules. An optional `opticalScale` in `suppliedLogos` can modestly reduce unusually dense wordmarks (default 1); verify the adjustment visually. Both logo and name links, accessible labels and safe external-link attributes are handled by the shared renderer in `staging-integration.js`.
5. Update the cache-version query on the changed supporter script/style references in `index.html`, so returning visitors receive the new roster and rendering. Verify homepage and `#/supporters` at desktop and mobile widths: logo visibility and spacing, no clipping or overflow, both links, totals, search and category filtering. Confirm existing logos still look correct and check for missing assets or JavaScript errors.
6. Preview the change for approval. Commit and publish when requested; verify the public page and new asset after deployment. A local preview is not the live site.

Only add public company information and supplied/approved logo artwork. Preserve the directory's distinction between an organization listing and endorsement of a particular policy proposal.

For a pale colored mark or noisy JPEG on white, optional `inkGain` and `inkCutoff` adjust the computed opacity (`gain × opacity − cutoff`) before the standard tone curve. Use conservatively and visually check fine lettering; defaults preserve existing rendering. These settings are ignored in alpha mode.
