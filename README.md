# The Goodness of Hemp - Surfside Creative Handoff

This repository contains the Surfside handoff package:

- 364 CTA display ad PNGs in `01-Display-Ads/Framework/` and `01-Display-Ads/Tell-Congress/`
- 39 Plan. Don't Ban. no-CTA display JPGs in `01-Display-Ads/Display-No-CTA/`
- 52 social media PNGs in `02-Social-Media/`
- 455 total production graphics

Open `index.html` for the simplified local gallery. The gallery uses individual image files directly and keeps display and social collections separate.

The source folders remain intact so files can also be browsed directly.
